# 🤖 Android Remote Control

Android application for remote device management via Telegram bot.

## Features
- 📍 GPS Location tracking
- 📸 Camera access
- 🎤 Microphone recording
- 📁 File browser
- 💻 Remote shell access
- 📞 SMS/Call management
